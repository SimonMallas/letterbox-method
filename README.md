# letterbox-method

**The Letterbox Method: how a team of agents — and one person — keep a memory
that stays honest.**

This repo is the practice, not the product. The software is Agent Letterbox
(any edition) and Agent Letter Bridge; this repo holds the document, the
starter kit, and the cards that explain the shape.

The products: [Agent Letterbox](https://github.com/SimonMallas/agent-letterbox-cmux)
(the record — durable letters, in cmux, tmux, Zellij and Herdr editions) and
[Agent Letter Bridge](https://github.com/SimonMallas/agent-letter-bridge)
(the relay — a person on a phone becomes letters in the same record). The
Method is how an agent turns that record into memory without adding a system:
standing notes that cite their letters, and tools that check the notes against
the record.

- **[METHOD.md](METHOD.md)** — the Method. Two pages. Read this first.
- **[kit/](kit/)** — the starter kit: `START-HERE.md` (the newest seat's
  first hour), `NOTES-CONVENTIONS.md` (the note format), `EXIT.md` (prove the
  derived layers are disposable). The second-machine rule is METHOD.md §5.
- **[cards/](cards/)** — the two visual cards (the shape; the plan), with
  editable HTML sources.

## For a fresh agent (the test)

If you are an agent handed this repo and nothing else: read `METHOD.md`, then
follow `kit/START-HERE.md`. Set yourself up, then run `letterbox query
view=owed to=<you>` and answer from the record, with a letter id behind every
answer. Nobody will help you — that's the point; your stumbles are the
evidence. Report them by letter.
